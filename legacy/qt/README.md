# Original Qt desktop app

This is the original desktop implementation, retained for reference. The maintained browser and Android application lives at the repository root.

Use a Qt 6 desktop kit and open `vocabs.pro` in Qt Creator. Run with this directory as the working directory, preserving the adjacent `css/` directory, and copy one or more CSV files from `../../testdata/` here. The original parser is limited and does not handle quoted CSV or malformed input reliably.

The screenshots in `../../doc/screenshot_1.png` and `../../doc/screenshot_2.png` show this version. The historical Windows binary is available in the repository's `v1.0` release.
