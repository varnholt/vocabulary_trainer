# Changelog

## 2.0.0

- Browser-first interface with a dependency-free C++17 training core compiled to WebAssembly.
- Offline Android app with local assets, CSV document selection, and system back navigation.
- Responsive card practice, keyboard controls, progress, completion feedback, and local list storage.
- CSV import and paste with quoted fields, UTF-8, BOM/CRLF support, multiline cards, and actionable input errors.
- Preserve multi-column Danish vocabulary lists and the original positive-score practice rule.
- Native regression checks on Windows, Linux, and macOS, browser integration tests, and Android build/lint in CI.
- GitHub Pages deployment, downloadable build artifacts, and versioned release packaging.
- Updated documentation, screenshots, issue forms, dependency updates, and contribution guidance.
- Preserve the original Qt implementation under `legacy/qt/` and retain the historical `v1.0` release.

## 1.0 — 2021-01-07

- Original Qt desktop vocabulary trainer and Windows binary.
