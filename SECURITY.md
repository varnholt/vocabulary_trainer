# Security

The maintained web and Android application is the supported version. The historical Qt app and `v1.0` binary are retained as-is.

Report vulnerabilities privately through the repository's **Security → Report a vulnerability** page. Include the affected version, platform, reproduction steps, and a minimal invented CSV example if relevant. Do not publish personal vocabulary or credentials in an issue.

The application processes lists locally. It has no account system or upload service. Keep original CSV files as backups, and keep your browser or Android System WebView updated.
